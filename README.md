# statescope site

A static explanation page for statescope: plain HTML, CSS and JavaScript modules. There is no build step to serve it, no backend,
no analytics, and no request to another host. Every address inside the site is relative.

```sh
python -m http.server --directory . 8000      # then open http://127.0.0.1:8000/
```

## Layout

- `index.html` is generated. Edit `tools/page.template.html` and run `tools/build_page.py`.
- `assets/css/site.css` holds the design tokens (light and dark) and all styles.
- `assets/js/` holds `main.js` (loading), `layers.js` (numbers per layer, spliced-in loss), `demo.js` (the line-count demonstration)
  and `svg.js` (helpers). The charts are hand-written SVG; no library is used.
- `assets/fonts/` holds Latin subsets of Pretendard (internal name changed to "Site Sans", as the Open Font License asks of a
  modified font with a reserved name) and of Geist Mono, with both licence texts.
- `data/` is generated by `tools/build_data.py`. Each file lists the source files it came from under `sources`.
- `CNAME` and `.nojekyll` are for GitHub Pages at statescope.ai.

## Rebuilding

The numbers come from a checkout of the statescope repository and from one output folder of its demonstration
(`python demo/line_count.py --release <weights> --out <folder>`).

```sh
python -B tools/build_data.py --repo <checkout> --hf-home <Hugging Face cache> --result <folder>   # torch, safetensors, transformers; CPU
python -B tools/build_page.py                                                                      # standard library
```

`build_data.py` stops if a sentence of the README that a number is read from has changed, if the generated per-layer strings
differ from `layers_table.md`, or if the generated shares differ from `line_count_table.md` and `line_count_link_table.md`.
`data/facts.json` records the commit of the checkout; `data/demo.json` records the sha256 of the two result files.

## Checking

```sh
python -B tools/lint_page.py --repo <checkout>                                           # numbers traceable, sentences, hygiene
python -B tools/check_numbers.py --repo <checkout> --result <folder> --hf-home <cache>   # numbers re-derived from the sources
python -B tools/verify_browser.py --repo <checkout>                                      # headless Chromium (playwright)
```
