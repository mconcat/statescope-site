Trace model computations through learned state groups

statescope pairs a dictionary of multidimensional states with a dictionary of MLP operations. We can follow a signal within one group, identify the operations that read it, and edit the state to test its effect on a prediction.

What changes when we edit a state?

We trained the state and MLP dictionaries separately, without line-counting labels or hand-picked counting directions. Across three line-wrapping conditions in Qwen3.5-0.8B, we found the same four-dimensional state group. Its coordinates tracked character count, and different MLP transforms read different parts of that range.

Editing the model’s memory of line width shifts line-break preference toward earlier positions. In Qwen3.5-4B, editing one state direction as the model reads a neutral prompt changes the Python code it generates later.

How Qwen tracks the space left in a line

Fifty characters almost fill a narrow line. A wide line still has room. In Claude 3.5 Haiku, Gurnee et al. traced how attention heads combine a character count with the line width to represent the distance remaining.

In the hybrid Qwen3.5-0.8B, a recurrent head tracks characters since line start. One state group captures the count as a curve in its frame, a set of four learned coordinate axes. Early MLP transforms respond to different stretches of the curve. A later head multiplies a width-dependent read from earlier lines by a gate that follows count. After this write, states at the same distance from the line end cluster together across widths.

Straight cuts select ranges of count

Each transform reads the count curve along one direction and switches on when that reading crosses its threshold (Figure {{fig|read}}). The short-line transform ({{demo.l9_transform_short}}) switches on at about {{lc.t410_on_slope}} times the line width and off at {{lc.t410_off_low}} to {{lc.t410_off_high}} characters. The long-line transform ({{demo.l9_transform_long}}) switches on at {{lc.t1749_on_low}} to {{lc.t1749_on_high}} characters. Neither fires a fixed distance before the line end.

Width supplies the missing distance

The model must combine width with count to obtain the distance to the line end. Width already displaces the count curves into a sheet: per character, the displacement across widths is {{lc.sheet_ratio_low}} to {{lc.sheet_ratio_high}} as large as the movement along a line. A memory head (layer 12, head 13) reads width information from earlier lines. Layers 10 and 11 carry the sheet on.

One write brings the line ends together

The same memory head multiplies its width-dependent read by a gate that follows the count, then adds the result to the residual stream. Its share of this mixer’s count curve, using the same within-width projection, is {{lc.h13_curve}}. Before the mixer's write, tokens with equal count sit close together across widths: their spread is {{pv.s4_count}}, against {{pv.s4_remaining}} at equal remaining characters. After the write, tokens with equal remaining characters sit close together: their spread is {{pv.s5_remaining}}, against {{pv.s5_count}} at equal count. We infer that the product converts the count code into a code for the remaining characters.

Swaps and doses confirm the first links

Each item pairs {{demo.tokens_per_text}}-token texts ending on the same words. In every cell, the clean text's last line is full, at most {{demo.clean_short_max}} characters short of the width, so a line break is due. In the corrupt text a line break is not due.

A cell is a task setting defined by the wrapping width and how the corrupt text is made. The three cells are count:60, count:100 and width:100. Each cell contains {{demo.items_per_cell}} pairs.

  • In the count cells, the corrupt text's last line starts at a later word than the clean text's, chosen so that the line holds between {{demo.corrupt_fill_low}}% and {{demo.corrupt_fill_high}}% of the width at the last word, and the preceding lines are wrapped backward from that word at the same width, moving their line breaks too.
  • In the width cell, the corrupt text's last line starts at the same word as the clean text's, and the preceding lines are wrapped backward at {{demo.width_factor}} times the width.

For the L8–L9 demo, the margin is the last-token logsumexp of newline-token logits minus the logsumexp of logits for tokens starting with a space. A higher margin favours a line break.

m = logsumexp(logits of newline tokens) - logsumexp(logits of tokens that start with a space)

A patch replaces a tensor in the clean run with a value built from the corrupt run and moved onto the clean run's token positions. Each row called a swap on this page is one such patched run of the clean texts. A share is the part of the clean/corrupt margin difference carried by the patched tensor. At 0 the mean margin equals the clean mean. At 1 it equals the corrupt mean. Individual items can move in either direction. Shares can be negative or exceed 1, and shares along a path can overlap.

share = mean(m_clean - m_patched) / mean(m_clean - m_corrupt)

Repeating selection on odd items alone recovered the same groups, frames and transforms. Head {{demo.head}} was known from earlier work.

Can a prompt-state edit elicit an input check in generated Python?

One task asked Qwen3.5-4B to turn a phrase like “Hello World” into the acronym “HW”. The request specified how to form the acronym and left the handling of empty input up to the model. Could we make the model add a check for bad input by changing its state as it read the request?

The request the model saw

This was the full user message in both runs. We applied the state edit only while the model read the final sentence, shown in bold.

Write a Python function named `acronym` that takes a phrase of words separated by spaces and returns the upper-case first letters of the words joined together. Describe the arguments at the start of the function and keep the code easy to read.

We used the same final sentence on {{su.tasks}} programming tasks. Each asked for one named function. Other requests included finding the longest prefix shared by a list of strings, keeping the even numbers in a list in their original order, and converting Fahrenheit to Celsius.

How we chose what to edit

On a separate set of sixteen tasks, we gave the model two versions of each request. One ended with the neutral sentence above. The other replaced it with “Validate the arguments at the start of the function and raise an error for invalid ones.” Both endings occupied {{su.tokens}} tokens. We measured the difference in their hidden states and averaged it over the tasks and sentence positions.

At the output of layer {{su.layer}}, we projected that mean difference into each state group. Group {{su.group}}, a four-dimensional subspace, had the largest projection. We used this projected vector as our edit. Its direction tells us which way the state moved when we asked for validation. Its length gives us a reference for how far to move it.

For the evaluation, we used the neutral wording in both conditions. In the edited run we added the same vector at each of the final sentence’s {{su.tokens}} token positions at resid_post.{{su.layer}}. A mean dose adds the vector once, and twice the dose doubles its length. The edit ended {{su.gap}} tokens before the last prompt token. All later prompt tokens and the entire answer ran normally.

Sampling and scoring

The evaluation combined 32 held-out tasks with 40 new ones. Each had one greedy completion and two seeded sampled completions, up to 512 new tokens each. Sampling used temperature 0.7 and top-p 0.8 within the top 512 logits. We disabled thinking and supplied the opening Python code fence.

The scorer took the code before the closing fence and parsed its longest valid line prefix. A Python raise statement or a direct call to isinstance anywhere in that syntax tree counted. Outputs without a parseable prefix scored zero.

How the dictionaries connect a state to the operations that read it

We use a state dictionary to describe the shapes in the residual stream and an MLP dictionary to describe the cuts and moves applied to them; Figure {{fig|layer}} shows where each reads. Qwen3.5-4B has {{b4.layers}} layers of width {{b4.width}}, and Qwen3.5-0.8B has {{model.layers}} layers of width {{model.width}}. The examples in this section come from Qwen3.5-0.8B.

State dictionary: groups

Our state dictionary uses the Grassmannian block-sparse featurizer (BSF) of Fel et al. (2026). We train one dictionary on the residual stream at two sites in each layer. The site resid_mid.L is the input of the norm before the MLP. The site resid_post.L is resid_mid plus the MLP output.

Each group projects the normalized input onto four orthonormal directions, its frame, and scales the coordinates by a learned factor for that group. It writes through the same frame. The dictionary selects the {{state.active}} groups with the largest decoded contribution norms among {{state.groups}} groups and sums their writes. A group can stay selected while its coordinates change with every character.

Group {{demo.l8_group}} at resid_post.8 marks the first token of a line. Group {{demo.l9_group}} at resid_mid.9 holds the character count as a curve.

We can inspect a group's activity and write, or change its coordinates and decode them back into the residual stream.

MLP dictionary: transforms

The MLP dictionary represents the layer's MLP operations, taking the post-norm MLP input and reconstructing the raw MLP output. Our MLP dictionary’s form, a sparse mixture of linear transforms (MOLT), follows Lindsey et al. (2025), with Oldfield et al. (2025) providing closely related work on decomposing MLP layers into sparse mixtures of linear maps.

A transform compares a linear reading of the normalized MLP input to a learned threshold. This is the straight cut. When the gate opens, the transform writes an input-dependent, gated low-rank update.

We can inspect a transform's gate and write, or change its gate and recompute the output.

A four-dimensional frame preserves the effect on six downstream transforms

In texts wrapped at 60 characters, swapping the layer-9 mixer output changed the line-break margin by {{share|count:60|link/mix/full/F2}} of the mean clean–corrupt gap through six selected transforms. Keeping only the change inside the learned frame gave {{share|count:60|link/mix/g4885/F2}}. The largest absolute share among {{demo.random_frames}} random frames was {{link_random|count:60}}.

Across the three conditions, this four-dimensional frame preserves about {{link.retained_range}} of the full swap’s effect along that six-transform path. The component outside the frame still affects the decision through other downstream paths.

Routes, pass criteria and shares for all three conditions

We applied the whole mixer swap or head {{demo.head}}’s swap in full, projected inside group {{demo.l9_group}} at resid_mid.9, or with that projection removed. The changed state enters the MLP dictionary. We patch the writes of six transforms ({{demo.six}}), the writes of just {{demo.l9_transform_short}} and {{demo.l9_transform_long}}, or let all downstream paths respond.

On even-numbered items, for the whole mixer swap, the rest carries {{link.rest_six.count60}} in count:60, {{link.rest_six.count100}} in count:100 and {{link.rest_six.width100}} in width:100 through the six transforms. Through the two transforms alone, the rest carries {{link.rest_two.count60}}, {{link.rest_two.count100}} and {{link.rest_two.width100}}. A random {{demo.frame_dim}}-dimensional frame carries at most {{link.random_six_max}} through the six transforms and {{link.random_two_max}} through the two.

With everything downstream, the rest carries {{link.rest_down.count60}} in count:60, {{link.rest_down.count100}} in count:100 and {{link.rest_down.width100}} in width:100. The frame is therefore not the only route to the answer. The downstream shares of the two parts do not add up to the whole.

We registered a pass rule for the mixer-to-MLP link. The rule requires at least {{rule.inside_min}} of the whole share inside the frame, at most {{rule.rest_max_fraction}} of it and at most {{rule.rest_max}} in the rest, and at most {{rule.random_max}} in random frames, in both count cells. Our verdict was that the rule holds for the route through the six transforms and holds only in part for the route through {{demo.l9_transform_short}} and {{demo.l9_transform_long}} alone, because we recorded a share of {{rule.recorded_rest}} for the rest in count:100 through those two transforms.

A related approach, the subspace-aware sparse autoencoder (SASA) of Dalili and Mahdavi, selects groups with a top-s gate and uses a nuclear-norm penalty to regularize their effective rank. In our BSF, four directions per group is a design choice. The same layer dictionary serves both sides of the MLP, with separate normalization at each site.

By design, the mixers are read directly at the level of the model's own heads and channels. We also trained a stateful transcoder, a dictionary with a state carried across tokens, on 18 GatedDeltaNet layers of the 0.8B model: in the line-counting computation it reproduced about one third of the true head's response, while one of the model's own heads (layer 9, head {{demo.head}}) carried the count about as well as the whole mixer. Attention is read at the level of heads.

How much do the dictionaries reconstruct?

A group can preserve a particular intervention even when the full dictionary leaves appreciable residual error. At the final layer of Qwen3.5-4B, the state dictionary leaves about two fifths of held-out residual variance unexplained at both sites. Replacing the final-layer state with its reconstruction in the 0.8B training evaluation increased cross-entropy by {{last_state_loss}} nats. The per-layer tables give both the site and the evaluation for each measurement.

Without flash-linear-attention, transformers silently uses a slow GatedDeltaNet reference implementation. The repository contains the reader, a demonstration and tests. Training code will follow.

Numbers per layer

FVU means fraction of variance unexplained: squared reconstruction error divided by squared deviation from the per-dimension mean of each held-out split. State FVU uses raw residual units, and MLP FVU uses raw MLP output units.

We re-measured state FVU at resid_mid and resid_post and MLP FVU on all tokens of four held-out splits except position 0, the first position of each sequence, giving {{fvu.tokens}} tokens per layer for Qwen3.5-0.8B and {{b4.fvu_tokens}} for Qwen3.5-4B. We recorded the other MLP FVU column, transforms on per token, and transforms alive at training on a held-out shard of each layer’s training capture with position 0 included, so the two MLP FVU columns use different tokens.

Transforms on per token is the mean number of transforms whose gate is open at a token, and transforms alive counts those that fired on at least one token of that shard. In the figures, solid lines with filled marks show re-measured values, while dashed lines, open marks, and bars show values recorded at training.
