Description

What statescope is

statescope contains a reader for per-layer dictionaries of {{set.model}}. The base model has {{model.layers}} layers and width {{model.width}}. Each layer has a state dictionary and an MLP dictionary that were trained separately. A state dictionary represents the residual stream at two sites of its layer. An MLP dictionary represents the layer's MLP operations, taking the post-norm MLP input and reconstructing the raw MLP output. This set contains no dictionaries for the mixers.

The repository contains the reader, a demonstration and tests. The trainers for this set are not in the repository.

One per layer, two sites

State dictionary

The state dictionary covers resid_mid.L and resid_post.L. The former is the input of the norm before the MLP. The latter is resid_mid plus the MLP output. The dictionary's tied form has {{state.groups}} groups of {{state.group_size}} directions. At each token, the {{state.active}} groups with the largest written norm are active.

The input is divided by its own size, and it is then standardised with a mean vector and one scale per site. Each layer's dictionary was trained on {{state.train_tokens}} tokens over {{state.train_steps}} steps.

One per layer

MLP dictionary

The MLP dictionary uses the sparse mixture of linear transforms, or MOLT, from the public crosslayer-transcoder code. It has {{mlp.transforms}} transforms in five rank tiers. There are {{mlp.tier1_n}} transforms of rank {{mlp.tier1_rank}}, {{mlp.tier2_n}} of rank {{mlp.tier2_rank}}, {{mlp.tier3_n}} of rank {{mlp.tier3_rank}}, {{mlp.tier4_n}} of rank {{mlp.tier4_rank}} and {{mlp.tier5_n}} of rank {{mlp.tier5_rank}}.

It uses a JumpReLU gate. Each transform has free read and write matrices. There is no skip connection. Training uses a tanh sparsity penalty. Training used {{mlp.train_steps}} steps of {{mlp.step_tokens}} tokens, or {{mlp.train_million_tokens}} million tokens, per layer.

Definitions

Mixer
A mixer is a layer's GatedDeltaNet or attention sublayer.
Site
A residual stream site is a location between the mixer and the MLP or after the MLP where a state dictionary reads the residual stream.
Group
A group is a set of {{state.group_size}} directions in a state dictionary.
Frame
A frame is the orthonormal basis of a group's {{demo.frame_dim}}-dimensional write subspace.
Code
A code gives a token's coordinates in that frame, multiplied by a per-group scale.
Transform
A transform is a linear operation in an MLP dictionary with its own read and write matrices. Its write is what it adds to the MLP output.
Gate
A gate controls a transform through a learned threshold on its pre-activation.

Reading the dictionaries

The reader is the single file src/statescope/reader.py. It needs torch, safetensors and PyYAML. It can be copied next to the weights. capture returns resid_mid, mlp_out and resid_post for the requested layer with position 0 dropped. It needs transformers and flash-linear-attention.

Reconstruction

Numbers per layer

FVU means fraction of variance unexplained. It is squared reconstruction error divided by squared deviation from the per-dimension mean of each held-out split. The state FVU is in raw residual units at the two state sites. The MLP FVU is in raw MLP output units.

Solid lines, filled marks

Measured by this repository

This repository measured the state FVU at both sites and the MLP FVU with its reader on all tokens of the original project's four held-out splits. The splits contain {{fvu.tokens}} tokens per layer, of which {{fvu.position_0_tokens}} are at position 0. Position 0 means the first position of each sequence.

The held-out activations are not published, so users cannot recompute these exact numbers.

Dashed lines, open marks

Recorded at training by the original project

The original project recorded the MLP FVU at training, the MLP transforms on per token and the MLP transforms alive on a held-out shard of each layer's training capture, with position 0 included. The shards were deleted afterwards. These numbers cannot be recomputed from the published files, and this repository did not repeat those measurements.

The two MLP FVU series differ because they are measured on different tokens.

Position 0, series measured by this repository

Transforms on per token is the mean number of transforms whose gate is open at a token. Transforms alive counts transforms that fired on at least one token of that shard, out of the total. The others never fired there. The sparsity penalty coefficient was {{mlp.penalty_main}} for layers {{model.first_layer}} to {{mlp.penalty_main_last_layer}}. Layer {{model.last_layer}} used {{mlp.penalty_last}} in a separate run. Position 0 matters for the state dictionary at some layers: at layer {{fvu.example_layer}}, resid_mid, the state FVU is {{fvu.l6_mid_with_p0}} with position 0 and {{fvu.l6_mid_dropped}} without it.

Spliced-in loss

Spliced-in loss is the increase in next-token cross-entropy when a dictionary reconstruction replaces the true activation in the forward pass, one layer and one dictionary at a time. The original project measured it in nats on text with clean cross-entropy {{splice.clean_ce}}. This repository did not repeat the measurement.

The original project used FineWeb-Edu rows outside the training mixture, taking the first {{splice.documents}} documents of at least {{splice.min_tokens}} tokens and the first {{splice.tokens_each}} tokens of each. Position 0 was not replaced. Loss was averaged over positions {{splice.first_position}} to {{splice.last_position}}, or {{splice.positions}} positions. The dictionaries are the released ones. The MLP result for layer {{model.last_layer}} comes from a separate measurement by the original project on the same kind of web text.

The earlier set had smaller increases. In the original project's comparison on the same text, the earlier set had smaller increases at all {{model.layers}} state layers and MLP layers {{model.first_layer}} to {{mlp.penalty_main_last_layer}}. For the state dictionary at layer {{splice.example_layer}}, it recorded {{splice.l9_state_here}} here against {{splice.l9_state_earlier}} for the earlier set. At layer {{model.last_layer}}, the released MLP dictionary had the smaller increase, {{splice.l23_mlp_here}} against {{splice.l23_mlp_earlier}} for the earlier set.

Demonstration

Line counting

The task uses texts wrapped to a fixed width. At the last word of a line, the model must predict a line break, so it must know how many characters the line already holds. Each item pairs {{demo.tokens_per_text}}-token texts ending on the same words. The clean text's last line is full. In the corrupt text, a line break is not due because the last line break was moved or all lines were wrapped wider.

The original project found the chain below. The script demo/line_count.py uses its chosen transform, group and head and re-measures their effects. It does not search for them. The shares, firing rates and per-item margins on this page are the output of one run of that script, read from its result.json and result.safetensors. No model runs in the browser.

Margin
The margin is the last-token logsumexp of newline-token logits minus the logsumexp of logits for tokens starting with a space.
m = logsumexp(logits of newline tokens) - logsumexp(logits of tokens that start with a space)
Patch, swap
A patch replaces a tensor in the clean run with a value built from the corrupt run and moved onto the clean run's token positions. Each row called a swap on this page is one such patched run of the clean texts.
Share
A share is the part of the clean/corrupt margin difference carried by the patched tensor. A share of 0 means that the patch changes nothing. A share of 1 means that the patch alone turns the clean run into the corrupt one.
share = mean(m_clean - m_patched) / mean(m_clean - m_corrupt)
Cell
A cell is a task setting defined by the wrapping width and how the corrupt text is made. The three cells are count:60, count:100 and width:100. In the count cells, the last line break moves. In the width cell, all lines are wrapped wider. Each cell contains {{demo.items_per_cell}} pairs.
Halves
The original project ranked transforms on the odd-numbered items and reads results on the even-numbered ones, {{demo.items_per_half}} items per cell. Some groups were first chosen after looking at all items; when the original project repeated the selection on odd-numbered items only, the chosen groups, frames and transforms were the same. Head {{demo.head}} was known from earlier work. Intervals are bootstrap intervals from {{demo.interval_low}} % to {{demo.interval_high}} %.

State group {{demo.l9_group}} of resid_mid.9

What the L9 transforms read of the mixer's write lies mostly inside the {{demo.frame_dim}}-dimensional frame of state group {{demo.l9_group}} of resid_mid.9. That part alone moves them about as much as the whole write. The rest moves them little but still reaches the answer through other routes. Group {{demo.l9_group}} is a dense group, not a sparse feature: some groups encountered by the original project on this task are dense {{demo.frame_dim}}-dimensional coordinates active on most tokens, and they carry information in their coordinates.

Transform {{demo.l9_transform_short}} is on while the line is short, and transform {{demo.l9_transform_long}} is on once it is long. Transform {{demo.l9_transform_short}} carries the L9 MLP's effect in count:60, and transform {{demo.l9_transform_long}} carries it in width:100.

Limits and what is not shown

Scope of the set

  • The set covers one model, 0.8B, and one dictionary seed.
  • There are no dictionaries for the mixers, which are the GatedDeltaNet and attention sublayers.
  • Other models, including Qwen3.5-4B, are outside this set.
  • Every comparison ran on one machine with one RTX 5090. A second machine, a different GPU model and a fresh pip install -e . into a new environment were not checked.
  • A pre-activation within float rounding of its hard threshold can be on in one computation and off in another.

The demonstration

  • It covers one model, 0.8B, and one dictionary seed, with texts wrapped to a fixed width.
  • This is an easy task for which the model has dedicated MLP neurons. The demonstration is not evidence that dictionary units are better than neurons.
  • State group {{demo.l8_group}} is sparse, but not every group is sparse. Some groups encountered by the original project on this task are dense {{demo.frame_dim}}-dimensional coordinates active on most tokens. They carry information in their coordinates. Group {{demo.l9_group}} is one of these dense groups, not a sparse feature.
  • The frame of group {{demo.l9_group}} is not the only route from the L9 mixer to the answer, and the registered pass rule for that link holds only in part for the route through transforms {{demo.l9_transform_short}} and {{demo.l9_transform_long}} alone.
  • The script takes the original project's choice of transform, group and head as given. It does not search for them.
  • Single-item margins of dictionary swaps are reproducible only to about {{demo.margin_repro}}. Shares are reproducible only to about {{demo.share_repro}}. A patched tensor is rounded to bf16. A {{demo.relative_difference}} relative difference between implementations flips some rounded elements.

What cannot be reproduced from the published files

  • Training cannot be reproduced because the trainers for this set are not in the repository. Porting them is planned.
  • The per-layer reconstruction numbers and the spliced-in loss cannot be reproduced because the held-out activations and texts behind them are not published.
  • The original project recorded MLP FVU, transforms on per token and transforms alive at training on a held-out shard of each layer's training capture. The shards were subsequently deleted, including the shard for layer {{model.last_layer}}'s separate run. These training-time numbers cannot be recomputed from the published files.

Measurements not repeated, and the comparison with the earlier set

  • This repository did not repeat the original project's training-time MLP held-out measurements or the spliced-in loss measurements.
  • No full-length training run was repeated for either design.
  • In the original project's spliced-in loss comparison on the same text, the earlier set had smaller increases at all {{model.layers}} state layers and MLP layers {{model.first_layer}} to {{mlp.penalty_main_last_layer}}.
